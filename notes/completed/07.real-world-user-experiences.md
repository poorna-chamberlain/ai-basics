### Why Claude Fails at UI

**The Root Causes** (from Anthropic's own postmortem):

1. **No Visual Verification**: Claude writes CSS it never sees rendered
2. **UI Drift**: Each session starts from zero, losing design memory between turns
3. **No Design System Memory**: Without `DESIGN.md`, Claude invents new colors/styles each time
4. **Old Defaults**: When Claude doesn't have explicit constraints, it defaults to safe, boring patterns
5. **Three Clichés Claude Repeatedly Produces**:
   - Warm cream background (#F4F1EA) + serif display + terracotta accent (90s blog look)
   - Near-black background + acid-green/vermilion accent (generic SaaS dark mode)
   - Broadsheet layout + hairline rules + dense columns (newspaper, 2000s era)

**Developer Quote** (Anthropic's own documentation):
> "AI-generated design right now clusters around three looks... If the output background is near `#F4F1EA` and the accent is terracotta, flag it."

## The Solution That Actually Works

### Layer 1: DESIGN.md (Design Memory)

**Problem**: Claude forgets your design system between sessions

**Solution**:
```markdown
# design.md - At your project root

## Colors
- Primary: #0066CC
- Accent: #FF6B35
- Background: #FFFFFF
- Text: #1a1a1a

## Typography
- Headings: Inter, 700, 28px line-height 1.2
- Body: Inter, 400, 16px line-height 1.5

## Spacing
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px

## Rules (CRITICAL)
- Only use colors defined above
- Only use fonts defined above
- Only use spacing values above
- No inventing new colors
- No default gradients without approval
```

### Layer 2: CLAUDE.md (Design Enforcement)

**Add to your CLAUDE.md**:
```markdown
## Design System

You must follow the design system strictly.

@design.md

### Design Rules
- Use ONLY colors, fonts, and spacing from design.md
- If a value isn't in design.md, ask before using it
- No cream backgrounds (#F4F1EA style)
- No generic dark modes with neon accents
- No newspaper-style layouts with hairlines
- Default to modern (2026+): rounded corners 6-8px, subtle shadows
- Verify responsive behavior: mobile, tablet, desktop
```

### Layer 3: SnapDiff (Visual Regression Testing)

**Problem**: Claude doesn't look at the rendered page

**Solution**: Use SnapDiff MCP server to force verification

```
Claude changes button → SnapDiff renders page → 
Detects: footer shifted, dark mode broken, layout broken →
Claude must fix before completing
```

**Real Result**: UI drift goes from constant to rare.

- Mar 26: Bug in session cleanup, made Claude forgetful
- Apr 16: System prompt changes hurt coding quality
- Result: Users reported degraded quality for months

**What Anthropic Did**:
- Published postmortem April 23, 2026
- Reverted changes
- Now: Enterprises default to `high`, $20 Pro users get `medium`

**Your Fix Now**:
```
In .claude/settings.json:
{
  "model": "claude-opus-5",
  "effort": "high"
}
```

### Problem 2: "UI Drift - my Claude Code frontends keep changing"

**Real Data**:
- Affects 100% of Claude Code users doing UI work
- Reported since early 2026
- Causes: No visual verification, no design memory, session context resets

**Solution That Actually Works** (Three Layers):

1. **DESIGN.md** - Define tokens once
2. **CLAUDE.md** - Reference and enforce
3. **SnapDiff MCP** - Mandatory verification

**Real Result** (from production teams):
- UI drift: 100% of sessions → ~5% of sessions
- Rework time: 60% of session → 10% of session
- Production ship rate: 40% first-pass → 90% first-pass

### Problem 3: "GPT-6 Astra is slow and expensive"

**Real Issues**:
- **1.8x slower than GPT-5.6 Sol** (16.8 min vs 9.5 min median)
- **3.7x more output tokens** than Claude Fable 5
- **Over-engineering**: Asks for massive PRs when you want targeted fixes

**Solutions**:
```
✅ Use Medium reasoning effort (not High or Max)
✅ Add explicit minimality instruction in prompts:
   "Make the smallest, most focused change. Avoid cleanup."
✅ Reserve Astra for long-horizon work, not quick tasks
✅ Use Luna ($1/$6) for volume work instead of Astra ($10/$50)
```

**Cost Comparison** (same task):
- GPT-6 Astra (Medium): $25.67 best cost
- GPT-5.6 Sol (High): $31.79
- Claude Opus 5: ~$35-40
- **Winner**: Astra Medium by 19%
