# Recycle Bin

Nothing is ever permanently deleted by the AI. Deleted items are moved here.

## Structure

recycle-bin/<YYYY-MM-DD>/<original-filename>

## Rules

- Organize strictly by date of deletion.
- Preserve the original relative path as a comment/note inside the file
  or in a per-day `manifest.md` listing what was moved and from where.
- Manual permanent cleanup is done by the user, not the AI.
